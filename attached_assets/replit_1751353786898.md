# Discord Bot Manager - Replit Configuration

## Overview

This application is a comprehensive Discord bot management platform built with a modern full-stack architecture. It enables users to create, configure, and manage multiple Discord bots with automated features like message posting and auto-responding. The system provides a web-based dashboard for bot configuration, real-time monitoring, and analytics.

## System Architecture

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Routing**: Wouter for client-side routing
- **UI Framework**: Radix UI components with shadcn/ui styling system
- **Styling**: Tailwind CSS with custom Discord-themed color scheme
- **State Management**: TanStack Query (React Query) for server state management
- **Form Handling**: React Hook Form with Zod validation
- **Build Tool**: Vite for development and production builds

### Backend Architecture
- **Runtime**: Node.js with TypeScript
- **Framework**: Express.js for REST API
- **Database ORM**: Drizzle ORM with PostgreSQL
- **Database Provider**: Neon Database (serverless PostgreSQL)
- **External API**: Discord.js for Discord bot integration
- **Task Scheduling**: Cron jobs for automated message posting
- **Session Management**: PostgreSQL-based session storage

### Project Structure
- `/client` - React frontend application
- `/server` - Express.js backend API
- `/shared` - Shared TypeScript types and database schema
- `/migrations` - Database migration files

## Key Components

### Database Schema (Drizzle ORM)
- **discord_bots**: Bot configuration and status tracking
- **auto_poster_configs**: Automated message posting settings
- **auto_responder_rules**: Message trigger and response rules
- **activity_logs**: System activity and error logging
- **message_templates**: Reusable message templates

### Discord Bot Services
- **DiscordBotManager**: Handles Discord client lifecycle and message processing
- **AutoPosterScheduler**: Manages cron-based automated posting
- **Storage Layer**: Abstracts database operations with in-memory fallback

### Frontend Pages
- **Dashboard**: Overview of bot status and activity
- **Bot Configuration**: Create and manage Discord bots
- **Auto Poster**: Configure scheduled message posting
- **Auto Responder**: Set up message triggers and responses
- **Multi-Account**: Bulk operations across multiple bots
- **Analytics**: Performance metrics and usage statistics
- **Templates**: Manage reusable message templates

## Data Flow

1. **Bot Creation**: Users create bots through the web interface, providing Discord bot tokens
2. **Configuration**: Bots are configured with channels, auto-posting schedules, and response rules
3. **Activation**: Backend initializes Discord clients and connects to Discord servers
4. **Message Processing**: Incoming Discord messages are processed against auto-responder rules
5. **Scheduled Posting**: Cron jobs trigger automated message posting based on configurations
6. **Activity Logging**: All bot activities are logged for monitoring and analytics
7. **Real-time Updates**: Frontend polls for updates to display current bot status

## External Dependencies

### Core Dependencies
- **Discord.js**: Official Discord API library for bot functionality
- **Drizzle ORM**: Type-safe database operations
- **@neondatabase/serverless**: Serverless PostgreSQL connection

### UI Dependencies
- **Radix UI**: Accessible component primitives
- **Tailwind CSS**: Utility-first CSS framework
- **Lucide React**: Icon library
- **React Hook Form**: Form state management

## Deployment Strategy

### Development
- Vite dev server for frontend hot reloading
- tsx for TypeScript execution in development
- Concurrent frontend and backend development

### Production Build
- Vite builds static frontend assets to `/dist/public`
- esbuild bundles backend code to `/dist/index.js`
- Express serves both API and static files
- Database migrations applied via `drizzle-kit push`

### Environment Configuration
- `DATABASE_URL`: PostgreSQL connection string (required)
- `NODE_ENV`: Environment mode (development/production)
- Discord bot tokens stored per-bot in database

### Replit-Specific Features
- Replit development banner integration
- Cartographer plugin for development environment
- Runtime error overlay for debugging
